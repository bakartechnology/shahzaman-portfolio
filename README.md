## 💻 Getting Started Locally

### 1. Clone & Install
```bash
git clone https://github.com/developwithshazzy/portfolio.git
cd portfolio
npm install
```

### 2. Configure Environment Variables (Optional)
```bash
cp .env.example .env.local
```
Add your keys if you want to forward contact inquiries through an email provider:
```env
NEXT_PUBLIC_SITE_URL=https://shahzaman-portfolio.vercel.app
RESEND_API_KEY=re_your_api_key_here
EMAIL_FROM=onboarding@resend.dev
EMAIL_TO=codebyshazzy@gmail.com
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 4. Build for Production
To test and create an optimized production build:
```bash
npm run build
```

### 5. Start Production Server
```bash
npm run start
```
